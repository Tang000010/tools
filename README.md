# 手机小工具

两个单文件、离线可用的网页小工具，手机上用 Safari 打开后可以「添加到主屏幕」当 App 用。

| 页面 | 说明 |
|---|---|
| [index.html](index.html) | 入口页，两个工具的卡片 |
| [mdpad.html](mdpad.html) | **Markdown 编辑器 / 阅读器**：左代码右实时预览，可切上下分栏、可关闭任一栏、分隔条可拖动；16 个常用语法快捷按钮；智能配对（`*` → `*\|*`，再按 → `**\*\***） |
| [det.html](det.html) | **矩阵计算器**：行列式 / 逆矩阵 / 伴随阵 / 矩阵连乘，全程分数精确运算 |

## 加到手机桌面

Safari 打开某个工具 → 底部「分享」→「添加到主屏幕」。
图标和标题已经配好（MD 编辑器 / 矩阵计算器），点开就是全屏，没有地址栏。

## 实现说明

- 纯前端单文件，无任何外部依赖、无 CDN，断网也能用
- 数值计算用 BigInt 分数，`1/3` 就是 1/3，不会出现 `0.333333` 或 `-1e-16`
- Markdown 渲染器是手写的（标题/强调/代码/引用/嵌套列表/任务/表格/分隔线/链接/图片），HTML 会被转义
- 编辑器内容存在浏览器 localStorage，自动保存
